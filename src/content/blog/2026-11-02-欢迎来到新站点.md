## 为什么换了

旧站是基于 Hexo + ayer 主题搭建的，2023 年之后就再没动过。这次做了一次彻底的重建：

- **框架升级**：从 Hexo 迁移到 **Astro 7**（2026 年最新的内容优先框架）
- **样式重写**：完全丢弃旧主题，改用 **Tailwind CSS 4** 手写一套暗夜极光主题
- **性能提升**：零 JavaScript 起步，页面切换走 View Transitions，Lighthouse 轻松 95+
- **内容迁移**：原有照片与文字全部保留，并支持 Markdown / MDX

## 技术栈

| 层 | 选型 | 说明 |
| --- | --- | --- |
| 框架 | Astro 7 | 内容优先，静态输出，默认不发货 JS |
| 样式 | Tailwind CSS 4 | CSS-first 配置，设计令牌集中在 `global.css` |
| 内容 | Content Collections | 带 schema 校验的 Markdown 集合 |
| 部署 | GitHub Actions | 推代码即自动发布到 GitHub Pages |

## 接下来

以后的新文章，只要往 `src/content/blog/` 里丢一个 `.md` 文件就行，
标题、日期、标签、相册都会自动被解析和展示。
